# Ролики к опытам

Каждый опыт лабораторной работы получил короткий ролик. Ролик показывает, что программа опыта делает с памятью и почему график опыта получается таким.

| № | Ролик | Файл сцены |
|---|---|---|
| 1 | Расслоение динамической памяти: банки, строки, точки T1 и T2 | `exp1_dram.py` |
| 2 | Ссылочные и векторные структуры: список против массива | `exp2_list.py` |
| 3 | Программная предвыборка: TLB и первое обращение к странице | `exp3_tlb.py` |
| 4 | Эффективное чтение памяти: отдельные массивы и один общий | `exp4_streams.py` |
| 5 | Конфликты в кэш-памяти: наборы, пути и шаг, равный банку | `exp5_conflicts.py` |
| 6 | Производительность кэш-памяти: ступени L1, L2, L3 | `exp6_cache.py` |
| 7 | Сортировки: QuickSort и Radix-Counting Sort | `exp7_sort.py` |
| 8 | Самомодифицирующийся код: режимы JIT и Branch в DOOM | `exp8_jit.py` |

## Откуда берутся графики

Графики роликов строит модель памяти из `model.py`, а не замер. Каждая модель оставляет одно явление опыта: банки памяти, линейки кэша, TLB, наборы кэша. Поэтому форма графика совпадает с опытом, а числа условные. Исключение составляет ролик 6: его времена сняты на Intel Core i5-8400.

Тест `test_model.py` проверяет форму каждого графика. Например, в ролике 1 первый пик стоит на шаге T1, пики растут до T2 и дальше не растут.

## Сборка

Ролики собирает [manim](https://www.manim.community/). Ему нужны `cairo`, `pango`, `pkgconf` и `ffmpeg`, на macOS их ставит Homebrew. Установите в систему шрифт GOST Type BU.

```sh
cd films
make install          # один раз: manim в venv
make test             # форма графиков
make preview N=1      # черновик ролика 1: 360p, 12 кадров/с
make film N=1         # ролик 1: 1080p, 30 кадров/с
make films            # все восемь роликов
```

Ролики появляются в папке `out/`. Промежуточные файлы manim лежат в `/tmp/memorylab-films`, папку задаёт переменная `MEDIA`. Скрипт `tools/manim-par.sh` делит ролик на куски и собирает их в `JOBS` процессах, по умолчанию в шести.

Основной `make all` проекта ролики не собирает: студенту manim не нужен.
