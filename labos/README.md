# labos

Компьютер загружает labos с флешки вместо операционной системы. labos проводит опыты лабораторной работы прямо на железе. Графики labos рисует на экране. Управлять им можно по сети командой `labctl.py`.

Операционная система мешает замерам. Она выделяет страницы при первом обращении, прерывает опыт ради других программ и скрывает физические адреса. Без неё опыты дают одни и те же числа от запуска к запуску, а опыт 1 видит настоящие банки DRAM.

## Что умеет

- Опыт 1 «Конфликты строк DRAM»: число банков, размер строки (страницы) и число страниц.
- Графики в стиле лабораторной работы: шрифт GOST Type BU, палитра Catppuccin.
- Управление по UDP: `ping`, `log`, `screen`, `run rowconf`, `reset`.

## Сборка

Нужны clang и lld-link из Homebrew (`llvm@22`, `lld@22`) или из пакетов Linux, а для QEMU ещё `qemu`.

```sh
make build         # build/esp/EFI/BOOT/BOOTX64.EFI
make test          # тесты чистых модулей на этой машине
```

## Запуск в QEMU

```sh
make qemu-headless # QEMU без окна, журнал в build/serial.log
make ping          # ответ labos по сети
make remote-screen # снимок экрана в build/remote.png
make stop
```

QEMU не моделирует время DRAM, поэтому опыт 1 там конфликтов не видит. Чтобы проверить рисунок, соберите labos с моделью памяти: `make build SYNTHETIC=1`.

## Запуск на компьютере

1. Отформатируйте флешку в FAT32 и запишите labos: `make usb VOLUME=/Volumes/LABOS`.
2. В настройках UEFI выключите Secure Boot.
3. Если нужно управление по сети, включите в настройках UEFI сетевой стек (Network Stack или PXE). Без него UEFI не даёт доступа к сетевой карте.
4. Загрузите компьютер с флешки.

В нижней строке экрана labos показывает свой адрес. Клавиша `1` запускает опыт 1, `Esc` перезагружает компьютер.

## Управление по сети

```sh
venv/bin/python3.12 tools/labctl.py --host АДРЕС ping
venv/bin/python3.12 tools/labctl.py --host АДРЕС --timeout 120 run rowconf 15 > rowconf.txt
venv/bin/python3.12 tools/labctl.py --host АДРЕС screen screen.png
```

`run rowconf 15` читает каждую пару 15 раз и берёт медиану. Ответ содержит выводы и строку данных на каждую линейку блока.
